## Columnas
| Columna | Uso |
|---|---|
| Backlog | Todas las tareas del proyecto al empezar. |
| Por hacer | Tareas del día en curso. |
| En progreso | Lo que se está trabajando ahora. Límite de 2 tarjetas a la vez. |
| En revisión / pruebas | Tareas terminadas que falta probar o revisar. |
| Hecho | Tareas terminadas, probadas y con commit. |

## Etiquetas
Documentación · Base de datos · Backend · Frontend · Pruebas · Git · Gestión

## Cómo se usó
- Cada día se mueven a **Por hacer** las tarjetas de ese día; al terminar pasan por **En revisión / pruebas** y luego a **Hecho**.
- Cada tarjeta tiene fecha límite según el plan de 10 días y una lista de verificación.
- El nombre de la tarjeta coincide con los commits del día (ver `docs/bitacora/`).
