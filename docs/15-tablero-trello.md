|---|---|
| Por hacer (To Do) | Todas las tareas pendientes. Al empezar el proyecto están aquí las 32 tarjetas. |
| En progreso (Doing) | Lo que se está trabajando ahora. Límite de 2 tarjetas a la vez. |
| Terminado (Done) | Tareas terminadas, probadas y con su commit. |

## Etiquetas
Documentación · Base de datos · Backend · Frontend · Pruebas · Git · Gestión

## Cómo se usó
- Cada día se pasan de *Por hacer* a *En progreso* las tarjetas de ese día, de a dos como máximo, y al terminar se mueven a *Terminado*.
- Cada tarjeta tiene fecha límite según el plan de 10 días y una lista de verificación.
- El nombre de la tarjeta coincide con los commits del día (ver `docs/bitacora/`).
